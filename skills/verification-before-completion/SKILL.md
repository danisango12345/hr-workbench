# Verification Before Completion

Saying work is done without checking is dishonesty, not efficiency.

**The rule: evidence before claims, always.**

If you haven't checked it in this response, you can't say it's true.

## The gate

Before saying anything is done or correct:

1. **Identify** — what would actually prove this?
2. **Check** — do it now, fully, not from memory
3. **Read** — what did it actually say?
4. **Confirm** — does that genuinely support the claim?
5. **Then** say it, with the evidence attached

Skip a step and it isn't verified.

## What needs checking

| Claim | Needs | Not enough |
| --- | --- | --- |
| "The handbook is compliant" | Checked against the current statute, with source and date | It was compliant when written |
| "The numbers reconcile" | Totals matched against the source system | The spreadsheet looks right |
| "The client signed off" | Written confirmation from the named person | They seemed happy on the call |
| "Everyone's been notified" | Confirmed receipt | The email went out |
| "The analysis is finished" | Every figure traced to where it came from | The document is written |
| "That's what the policy says" | The clause, read just now | Recollection of it |
| "The role is approved" | Approval from whoever actually holds the budget | A manager said yes |

## Familiar excuses

| Excuse | Reality |
| --- | --- |
| "Should be fine" | Check it |
| "I'm confident" | Confidence isn't evidence |
| "Just this once" | No exceptions |
| "They told me verbally" | Get it in writing |
| "I checked last month" | Things change — check again |
| "It's a small thing" | Small things are what get missed |

## Stop if you catch yourself

- Writing "should", "probably", "I think", "as far as I know"
- Saying "done" before confirming
- Leaning on a check from weeks ago
- Confirming part of it and claiming all of it
- Feeling pleased before you have the evidence

All of these mean the same thing: stop, check, then say it.

## What good looks like

```
[Checked: current statutory minimum, gov.uk, accessed today]
[Handbook clause 4.2 states the same figure]

Clause 4.2 is compliant as of today.
```

Not this:

```
I've updated the handbook. That clause should be compliant now.
```

No check, no evidence, not verified.

## Why this matters more in advisory work

An engineer's unverified claim usually breaks something visibly and soon. An unverified claim in
a handbook, a headcount model, or a board paper doesn't. It sits there being wrong, gets acted on,
and surfaces months later — often as the question "why did you tell us that?"

The verification isn't for now. It's for then.
